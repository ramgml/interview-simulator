# Тестовая вакансия: Python-разработчик (middle)

> Тестовые данные для сквозной проверки тренажёра (docs/PRD.md, «Метрики успеха», п. 1 — E2E на тестовой вакансии: сессия создаётся, вопросы звучат, follow-ups тематические, отчёт полный). Вакансия намеренно покрывает все четыре раунда плана интервью — technical, behavioral, algorithms, system_design.

## Позиция

**Python-разработчик (middle)** — продуктовая команда «Логистика»

- **Формат:** удалённо (компания распределённая, головной офис в Москве), полная занятость.
- **Вилка:** 250 000 – 350 000 ₽ на руки, финальное решение — по результатам собеседования.

## О компании

B2B SaaS-платформа для управления последней милей доставки: маршрутизация, приложение курьера, трекинг для покупателя. Более 40 клиентов в ритейле и фудтехе, около 2 млн доставок в месяц. Продукт построен как набор микросервисов на Python, фронтенд — на Next.js.

## Описание

Ищем Python-разработчика в команду ядра — сервисы маршрутизации и тарификации. Это высоконагруженная часть продукта: десятки тысяч запросов в минуту, gRPC между сервисами, Kafka как событийная шина. Нужно писать новый код, выносить переиспользуемое в библиотеки, разбирать продакшн-инциденты и участвовать в проектировании новых сервисов.

## Стек

- Python 3.12, asyncio, FastAPI
- SQLAlchemy 2.0 (async), Alembic, PostgreSQL
- gRPC для межсервисного общения, REST для публичного API
- Kafka (события домена), Redis (кэш и распределённые блокировки)
- Docker, Kubernetes, Helm
- GitLab CI/CD, канареечные релизы
- pytest, ruff, OpenTelemetry, Prometheus/Grafana

## Чем предстоит заниматься

- Проектировать и разрабатывать сервисы на FastAPI: роутинг, тарификация, расчёт ETA.
- Проектировать схемы PostgreSQL и оптимизировать запросы (планы, индексы, партиционирование).
- Развивать gRPC-контракты между сервисами и их версионирование.
- Участвовать в разборе инцидентов и постмортемах; дежурства раз в шесть недель.
- Покрывать код автотестами; перед релизом крупной фичи — нагрузочные сценарии.

## Наши требования

- Коммерческая разработка на Python: 3–5+ лет.
- Уверенный асинхронный Python (asyncio) и FastAPI: продакшн-опыт, а не пет-проекты.
- SQLAlchemy ORM, проектирование схем PostgreSQL, оптимизация запросов.
- Алгоритмы и структуры данных: умение оценить сложность решения (Big-O) и объяснить выбор.
- Docker и Kubernetes: сборка образов, деплой, отладка подов.
- Опыт работы в микросервисной архитектуре: REST и gRPC API, идемпотентность, ретраи, таймауты.
- CI/CD: понимание пайплайна от коммита до продакшна, культура код-ревью.

## Бонусом

- Kafka: партиционирование, порядок событий, семантика exactly-once — когда она нужна, а когда нет.
- OpenTelemetry, трассировка распределённых запросов.
- Опыт миграций PostgreSQL без даунтайма.
- Вклад в open source (FastAPI, SQLAlchemy или инфраструктурные библиотеки).

## Условия

- Удалённая работа; пересекающийся интервал 12:00–17:00 МСК, остальное — как удобно.
- Оформление по ТК РФ или через ИП/самозанятость; ДМС со стоматологией после испытательного срока.
- Бюджет на конференции и курсы, внутренние технолки раз в две недели.
- Релизы два раза в неделю, канареечные, без ночных ручных деплоев.

## Почему вакансия годится для E2E-теста

- **technical** — FastAPI/asyncio, SQLAlchemy, планы запросов PostgreSQL: достаточно конкретики для вопросов и тематических follow-ups.
- **behavioral** — дежурства, инциденты, код-ревью, канареечные релизы: есть о чём спрашивать про реальный опыт.
- **algorithms** — требование Big-O прописано явно: планировщик может заложить раунд на структуры данных и оценку сложности.
- **system_design** — микросервисы, gRPC, Kafka, Kubernetes: можно попросить спроектировать фрагмент платформы, например трекинг статусов доставки.
